# ggsegMiccai: MICCAI 2012 Multi-Atlas Labeling Brain Atlas for the 'ggseg' Ecosystem

Neuromorphometrics maximum probability tissue labels, derived from the
MICCAI 2012 Grand Challenge and Workshop on Multi-Atlas Labeling and
distributed with SPM12, for the 'ggseg' ecosystem. Provides cortical and
subcortical 'ggseg_atlas' objects with both 2D polygon geometry and 3D
vertex indices, for use with 'ggseg' and 'ggseg3d'. The label data are
released under CC BY-NC; MRI scans originate from the OASIS project and
the labeled data are provided by Neuromorphometrics, Inc. under academic
subscription.
